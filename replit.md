# James Jiang Personal Website

## Overview
A pre-built static personal website/portfolio for James Jiang, a Network Engineer/Security Engineer/SRE. Built with React and bundled with Vite.

## Project Structure
- `index.html` - Main entry point
- `404.html` - 404 error page
- `assets/` - Bundled JS, CSS, and images
- `server.py` - Python HTTP server for local development
- `favicon.png` - Site favicon

## Running Locally
The site is served using a Python HTTP server on port 5000:
```
python server.py
```

## Deployment
Configured as a static site deployment, serving files from the root directory.
